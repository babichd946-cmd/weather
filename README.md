## Weather Analytics App

Інтеграційний вебзастосунок на основі Python (Flask), розроблений для пошуку, аналізу та локального зберігання погодних даних через публічний API **OpenWeatherMap**.

---

## Основний функціонал
- Пошук погоди за містом (`/`): Отримання актуальних даних: температура, вологість, тиск, швидкість вітру, умови та можливість збереження запису в локальну базу даних.
- Мультиміське порівняння та аналітика (`/compare`): Введення кількох локацій через кому, формування порівняльної таблиці та автоматична генерація аналітичних графіків за допомогою бібліотеки `matplotlib` температури та вологість в один рядок [cite: 45].
- Керування збереженими записами (`/saved`): Перегляд, локальний пошук/фільтрація за назвою міста, редагування та видалення записів CRUD-операції.
- Власний REST API (`/api/items`): Повноцінний програмний інтерфейс для отримання, створення, оновлення й видалення записів у форматі JSON з підтримкою кодів відповіді `200`, `201`, `400` та `404`[cite: 45].
- Дизайн Solar Orchard: Оформлення інтерфейсу в темних тонах на базі Bootstrap 5 та кастомного CSS.

---

## Технологічний стек
- Backend: Python 3.10+, Flask 3.x
- Database: SQLite (з параметризованими запитами для захисту від SQL-ін'єкцій)
- External API**: OpenWeatherMap (Current Weather Data)
- Data Visualization: Matplotlib
- Frontend: Bootstrap 5, HTML5, CSS3

---

## Структура бази даних (`weather_records`)
| Поле | Тип | Опис / Обмеження |
| :--- | :--- | :--- |
| `id` | INTEGER | Первинний ключ (Primary Key, автоінкремент) |
| `city_name` | VARCHAR(100) | Назва міста (`NOT NULL`) |
| `temperature` | FLOAT | Поточна температура у °C |
| `humidity` | INTEGER | Вологість у % |
| `wind_speed` | FLOAT | Швидкість вітру (м/с) |
| `condition` | VARCHAR(100) | Текстовий опис погодних умов |
| `external_id` | INTEGER | Зовнішній ID міста з OpenWeatherMap |
| `recorded_at` | TIMESTAMP | Час збереження запису (за замовчуванням — поточний) |
